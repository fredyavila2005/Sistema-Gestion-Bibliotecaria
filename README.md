# SGB — Sistema de Gestión Bibliotecaria
Proyecto de Programación Orientada a Objetos (Python + Google Colab).

## Cómo ejecutar
1. Abrir `SGB.ipynb` en Google Colab.
2. Ejecutar todas las celdas en orden (Entorno de ejecución → Ejecutar todo).
3. Autorizar el acceso a Google Drive cuando se solicite.

Los datos se guardan en `MyDrive/SGB/datos/`.
